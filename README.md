# Hola, mundo!!!!!

Una página web sencilla de bienvenida, hecha con HTML, CSS y JavaScript nativos. Incluye un saludo que puedes cambiar y un reloj analógico que muestra la hora local.

## Funcionalidades

- Cambia entre distintos mensajes con el botón **Cambiar saludo**.
- Muestra un reloj analógico que se actualiza cada segundo.
- Adapta su presentación a pantallas pequeñas.
- Incluye detalles de accesibilidad, como texto alternativo para la hora y estados de foco visibles.

## Cómo empezar

No necesitas instalar dependencias ni compilar el proyecto.

1. Clona el repositorio o descarga sus archivos.
2. Abre `index.html` en tu navegador.

También puedes servir la carpeta localmente con Python:

```bash
python -m http.server 8000
```

Después, abre [http://localhost:8000](http://localhost:8000) en el navegador.
